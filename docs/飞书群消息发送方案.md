## 📢 @全员通知规范

### 标准格式
```
📢 [通知标题]

<at user_id="ou_xxx">姓名</at> <at user_id="ou_yyy">姓名</at> ...

[通知正文内容]

---
[落款/签名]
```

### 关键点
1. **必须@每一个人** - 使用 `<at user_id="xxx">name</at>` 格式
2. **不要依赖群@all** - 飞书机器人不支持@all
3. **逐个列出成员** - 确保每个人都收到通知
4. **清晰的结构** - 标题 + 被@人 + 正文 + 落款

## ⚠️ 注意事项

### 格式规范
1. **飞书不支持 Markdown 表格** - 使用 bullet lists 代替
2. **支持基础 Markdown** - `**bold**`, `_italic_`, `` `code` ``
3. **@语法** - 必须使用 `<at user_id="xxx">name</at>` 格式
4. **链接** - 多个链接建议用 `<>` 包裹抑制 embed

### 发送时机
1. **避免深夜打扰** - 23:00-08:00 除非紧急
2. **批量通知** - 相似内容合并发送，避免刷屏
3. **重要通知** - 使用@全员确保触达

### 权限相关
1. **机器人权限** - 确保应用已添加到群聊
2. **消息类型** - 文本消息最稳定，富文本需测试
3. **频率限制** - 避免短时间内大量发送

## 🔧 故障排查

### 常见问题

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| 消息发送失败 | 群聊 ID 错误 | 检查 target 参数 |
| @不生效 | UserID 错误 | 核对成员 UserID |
| 格式混乱 | 使用了不支持的 Markdown | 改用飞书支持的格式 |
| 机器人无响应 | 应用未授权 | 检查 App 权限配置 |

### 调试步骤
1. 确认群聊 ID 正确 (`oc_xxxxxxxxxx` 格式)
2. 确认 UserID 正确 (`ou_xxxxxxxxxx` 格式)
3. 检查飞书应用权限 (scopes)
4. 查看消息发送返回结果
